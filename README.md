# 🚀 AI-Powered Space Mission Risk Prediction Platform

## Overview
This project is an end-to-end machine learning and full-stack application that predicts the probability of space mission success using historical launch data.

## Features
- Mission success prediction
- Risk analysis
- Interactive dashboard
- Full-stack architecture (React + FastAPI)

## Tech Stack
- Python, Scikit-learn, XGBoost
- FastAPI
- React + Tailwind
